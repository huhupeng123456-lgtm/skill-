# 小红书爆款笔记写作助手

从零开始写出一篇**可直接复制到小红书发布**的图文笔记。核心目标：降低用户的思考成本，给读者明确的"获得感"。

---

## 目标用户

已经掌握小红书基础理论、需要**直接产出内容**的创作者。本 skill 的作用是：
- **写作引擎**：输入选题和赛道，输出完整可用的笔记
- **爆款公式化**：把"凭感觉写"变成"按结构填"
- **多源融合**：给你 2-3 篇同主题爆款，提取它们共同传递的"那件事"，用新表达方式重写

---

## 两种工作模式

本 skill 支持两种输入方式，触发时自动识别：

| 模式 | 输入 | 输出 |
|------|------|------|
| **模式 A：单篇原创** | 赛道+选题+人设 | 从零写出一篇完整笔记 |
| **模式 B：多源融合** | 2-3 篇同主题对标笔记 | 拆解→提取共识→用新表达重写 |

**模式 B 的适用场景**：
- 你看到 2-3 篇讲同一件事但都爆了，想融合它们的优点
- 你想写"减脂怎么训练"，但不想跟任何人一样，只想提取爆款结构再换壳
- 你想把抖音/公众号/微博上的 2-3 篇内容，融合成一篇小红书图文

---

## 核心方法论来源

本 skill 与 `xhs-note-analysis` 共用同一套底层框架：
- **钩子**：9种（人间美好/否定性力量/与我相关/反常/特殊消息/不稳定状态登场/窥探/优越与冒犯/新奇有趣）
- **骨架**：可复用的内容结构流程
- **刺点**：点赞/收藏/评论/传播/关注 五类互动触发

同时融合用户 OBS `笔记/自媒体/自媒体.md` 中的实战经验：
- 爆款三要素：**痒点/痛点/爽点**
- 标题公式：**给结果不给过程 / 戳痛点反常识 / 结论先行**
- 内容原则：**有用性第一、观点绑定经历、降低思考成本**
- 关键词三层布局：**核心词 → 长尾词 → 蓝海词**
- 评论区运营：**抢占第一条评论、2小时黄金回复期**

## 写作流程

### Phase 0：确认输入模式

每次触发必须先判断用户是**模式 A** 还是**模式 B**，并收集对应信息。

#### 模式 A（单篇原创）输入确认

如果用户只给了一个选题，没有提供对标笔记，按此模式走：

```
【模式】A
【赛道】____（如：健身/职场/育儿/AI/美食）
【选题】____（具体要写什么，如"减脂不掉肌肉"）
【目标人群】____（越具体越好，如"30岁久坐上班族"）
【人设】____（你的身份标签，如"35岁二胎妈妈/5年产品经理"）
【变现模式】____（线索转化/接广告/矩阵，影响内容软硬度）
【笔记形式】____（图文/视频文案/纯文字）
```

#### 模式 B（多源融合）输入确认

如果用户提供了 2-3 篇笔记（或说"参考这几篇""融合一下""照着这个结构写"），按此模式走：

```
【模式】B
【赛道】____
【核心主题】____（这 2-3 篇共同讲的是什么？如"减脂期力量训练怎么安排"）
【目标人群】____（你想写给谁？可以与对标不同）
【人设】____（你的身份标签）
【提供的对标笔记】____（逐一列出）
【融合要求】____（保留什么、换掉什么、新语气风格）
```

**模式 B 关键规则**：
- 必须至少提供 2 篇，最多 3 篇
- 这 2-3 篇必须讲**同一件事**（核心信息相同），但表达方式不同
- 如果 3 篇主题差异太大，告知用户"这 3 篇讲的不是同一件事，融合会杂。建议换一组或只选 2 篇"

**唯一前提**：用户本次产出的目的是**为了写小红书图文笔记**。

---

### 模式 B 专属流程（多源融合）

当用户提供了 2-3 篇同主题对标笔记时，先走以下 Phase，再走共用的 Phase 1-5。

#### Phase B1：分别拆解每篇对标笔记

逐篇拆解，用大白话总结（不用输出完整分析，只提取关键要素）：

```
═══════════════════════════════════
  【融合】Step 1：拆解来源
═══════════════════════════════════

【来源 1】____
- 钩子类型：____
- 标题公式：____
- 骨架类型：____
- 核心信息：____（这篇用一句话说，传递了什么）
- 最强刺点：____（哪句话最容易触发点赞/收藏/评论）
- 语气风格：____

【来源 2】____
（同上格式）

【来源 3】____（如有）
（同上格式）
```

**拆解原则**：
- 只提取**可复用的结构要素**，不复制具体措辞
- 每篇的"核心信息"用同一句话概括，验证它们是否真的在讲同一件事

#### Phase B2：提取共识（共同传递的"那件事"）

```
═══════════════════════════════════
  【融合】Step 2：提取共识
═══════════════════════════════════

【共识核心信息】____（2-3 篇都在说的同一件事）

【共识钩子类型】____（多篇都用了哪种类型的钩子）
【共识骨架动作】____（多篇共同的动作流程，如：亮结果→给步骤→稳心态）
【共识刺点分布】____（多篇都在哪段埋了点赞/收藏/评论）

【为什么这个结构有效】____（大白话解释这个主题下，读者最需要什么）
```

#### Phase B3：差异化分析（每篇的独特优势）

```
═══════════════════════════════════
  【融合】Step 3：差异化分析
═══════════════════════════════════

【来源 1 的独特优势】
- 独有的钩子：____（其他篇没用到的）
- 独有的细节：____（具体数字/场景/经历）
- 独有的刺点：____
- 语气特色：____

【来源 2 的独特优势】
（同上格式）

【来源 3 的独特优势】（如有）
（同上格式）

【融合策略】____（从多篇中各取什么优势组合到新笔记中）
```

#### Phase B4：确定新表达方式

```
═══════════════════════════════════
  【融合】Step 4：新表达定位
═══════════════════════════════════

【新笔记的人设】____（与来源不同，是你的身份）
【新笔记的语气】____（如：更硬核/更絮叨/更冷静）
【保留的结构】____（从共识中提取的动作流程）
【替换的元素】____
  - 目标人群：从____换成____
  - 场景细节：从____换成____
  - 具体数字/经历：从____换成____
  - 话语体系：从____换成____

【融合后钩子类型】____（保留共识钩子 + 叠加来源 X 的独特钩子）
```

**融合核心规则**：
- **保留动作，不保留句式**（同 xhs-note-analysis 的改写原则）
- **保留骨架逻辑，替换话语体系**
- **把多篇的优势拼成一篇**：来源 A 的钩子 + 来源 B 的刺点 + 来源 C 的细节密度
- **新笔记必须有独立语气风格**，不能是"来源 1 换个词"

---

### Phase 1：选钩子 + 定标题（模式 A 和 B 共用）

**标题是笔记的命脉**，必须在 20 字以内（建议≤18字），前半段放关键词。

**从以下 3 个标题公式中选 1-2 个组合使用**：

| 公式 | 说明 | 示例 |
|------|------|------|
| **给结果，不给过程（抛悬念）** | 给出诱人结果，隐藏具体方法 | "10个问题筛出无效Offer" |
| **戳痛点/反常识开头** | 前5秒精准击中恐惧或颠覆认知 | "大厂大多数人其实真的很水" |
| **结论先行（甩结论）** | 直接给出明确、数字化、具象化结果 | "3个万能公式，10分钟搞定AI面试" |

**叠加 9 种钩子类型**（参考 xhs-note-analysis 的 `002-钩子方法论.md`）：
- 强钩子优先：**反常、与我相关、否定性力量、窥探、不稳定状态登场**
- 可叠加 2-3 种，但不能超过 4 种导致信息过载

**输出格式**：
```
═══════════════════════════════════
  一、标题方案
═══════════════════════════════════

【推荐标题】____（≤20字，前半段含关键词）
【钩子类型】____（9种中的哪几种叠加）
【标题公式】____（给结果/戳痛点/结论先行）
【为什么能点进来】____（一句大白话讲清心理机制）

【备选标题】____
【备选标题】____
```

---

### Phase 2：搭骨架

**骨架 = 正文从第1段到最后1段的"动作流程"**，必须让读者的思考成本降到最低。

**爆款笔记的 5 种经典骨架类型**（根据选题自动匹配）：

#### 类型 A：成果验证型
**适用**：个人经验分享、逆袭蜕变、数据背书类
**结构**：
① 亮结果（时间+数字+意外好处）→ ② 说手段（一句话概括核心方法）→ ③ 给建议1 → ④ 给建议2 → ⑤ 给建议3 → ⑥ 收尾稳心态

#### 类型 B：痛点解决型
**适用**：教程、攻略、避坑、方法论
**结构**：
① 戳痛点（具体场景+情绪共鸣）→ ② 给承诺（"我帮你解决了"）→ ③ 步骤1 → ④ 步骤2 → ⑤ 步骤3 → ⑥ 结果验证+号召行动

#### 类型 C：观点冲击型
**适用**：反常识、认知升级、行业揭秘
**结构**：
① 抛出反常识观点 → ② 讲亲身经历/案例 → ③ 拆解底层逻辑 → ④ 给出可操作建议 → ⑤ 金句收尾

#### 类型 D：系列连载型
**适用**：系列内容、合集、清单
**结构**：
① 报身份+系列预告 → ② 今天讲第X点 → ③ 展开细节 → ④ 预告下期 → ⑤ 关注钩子

#### 类型 E：情绪共鸣型
**适用**：故事、感悟、人际、情感
**结构**：
① 场景代入（具体画面）→ ② 冲突/转折 → ③ 情绪爆发点 → ④ 感悟/结论 → ⑤ 互动提问

**输出格式**：
```
═══════════════════════════════════
  二、骨架设计
═══════════════════════════════════

【骨架类型】____型
【适用场景】____

【结构流程】
① ____（这段的作用：____）
② ____（这段的作用：____）
③ ____（这段的作用：____）
...

【内容配比提醒】
- 专业内容 vs 人设内容：____% vs ____%
- 情绪价值 vs 实用价值：____ vs ____
```

---

### Phase 3：埋刺点

**刺点 = 引导读者点赞/收藏/评论/关注的触发机制**。

**必须至少埋 3 处刺点**，分布规则：
- **点赞刺点**：加粗金句、情绪高点、共鸣观点（放在段落收束处）
- **收藏刺点**：具体数字/步骤/清单/模板（放在正文中段或结尾）
- **评论刺点**：结尾抛具体问题（二选一比开放题更容易被回答）
- **关注刺点**：系列感预告、"主页还有XX"、人设露出

**输出格式**：
```
═══════════════════════════════════
  三、刺点布局
═══════════════════════════════════

【点赞刺点】
位置：第__段
埋法：____（原文那句话）

【收藏刺点】
位置：第__段
埋法：____（可抄走的清单/数字/步骤）

【评论刺点】
位置：第__段
埋法：____（具体问题，引导回答）

【关注刺点】
位置：第__段
埋法：____（系列预告/人设价值）
```

---

### Phase 4：生成完整笔记

**输出必须达到"直接复制到小红书微调即可发布"的完成度**。

**字数硬限制**：
- 标题：≤20 字（建议≤18，留余量给话题标签）
- 正文：≤1000 字（建议≤950，留余量）
- 标签：3-5 个（1个大流量 + 2-3个精准细分）

**输出格式**：
```
═══════════════════════════════════
  四、完整笔记
═══════════════════════════════════

【标题】
____

【正文】
____

【标签】
#____ #____ #____

【封面建议】
- 文字内容：____
- 风格：____
- 配色：____

【评论区钩子】（发布后立即发第一条评论）
____
```

**写作规则**：
- **口语化**：像跟朋友聊天，不是写论文
- **有专属细节**：具体数字、具体场景、具体感受 > 泛泛而谈
- **观点绑定经历**：每个干货观点后面，必须有真实个人故事/细节支撑
- **直观语言 > 抽象语言**："我每天四点起来熬汤" > "我是一个勤奋的人"
- **do句式 > be句式**：动作+结果 > 形容词自我描述
- **不要纯AI味**：允许跑题、题外话、半成型的想法，允许"我真的不知道该怎么看待这件事"

### Phase 5：发布前自检清单

生成完笔记后，逐条自查：

```
═══════════════════════════════════
  五、发布前自检
═══════════════════════════════════

- [ ] 标题是否≤20字？前半段是否含关键词？
- [ ] 标题是否用了"给结果/戳痛点/结论先行"至少一种公式？
- [ ] 正文是否回答了"我学这个能干嘛"？
- [ ] 观点是否绑定了真实个人经历/细节？
- [ ] 是否有具体数字建立信任？
- [ ] 是否埋了至少1处点赞刺点？
- [ ] 是否埋了至少1处收藏刺点（可抄的干货）？
- [ ] 是否埋了至少1处评论刺点（具体问题）？
- [ ] 标签是否3-5个（1大流量+2-3精准）？
- [ ] 是否有敏感词/绝对词（万能/第一/最好）？
- [ ] 读完是否感觉"这人说的是人话"？
```

## 发布后 SOP（附赠）

笔记发出后按这个流程运营：

| 时间段 | 操作 |
|--------|------|
| **0~2小时** | 先发第一条评论补充干货；秒回用户评论（回复要有引导性）；分享到微信/小红书群 |
| **2~24小时** | 保持评论区热度，持续观察数据 |
| **数据达标后** | 互动率 > 8% 可投薯条试水 |
| **2天后** | 搜索查排名，看目标关键词排第几 |

**评论区运营原则**：
- 评论权重 = 点赞的 4 倍，评论区是数据主战场
- 自己发的第一条评论，补充干货或抛出争议观点
- 2小时黄金回复期：只要有评论必须秒回，激发二次互动

## 不适合写的选题

| 类型 | 原因 |
|------|------|
| 纯视觉向（穿搭九宫格、风景大片） | 吸引力在图不在字，文案几乎为空 |
| 明星/公众人物号 | 靠身份获取流量，不可复制 |
| 纯种草带货硬广 | 商业逻辑不是内容逻辑 |
| 范围太宽泛 | "女性成长""AI"不是有效选题，必须聚焦到具体维度 |

---

## 输出语言与风格

- 全程使用**中文**输出
- 术语要浅，示范要清楚
- **直观语言 > 抽象语言**，**有专属细节 > 泛泛而谈**
- 允许口语化、允许跑题、允许不完美的结构
- 目标用户是已经懂理论、需要直接产出的创作者
