# 建构学习框架

本文件是 `explain` 的内部学习设计底座。不要机械向用户展示术语；只把它们转化为能帮助当前判断的普通话。

## 1. 先把学习名称改写成最终任务

不要把“理解 API”“掌握 RAG”直接当作完成目标。优先改写为：

> 当用户未来面对 `{某类输入}` 时，能够独立产生 `{正确判断、解释或输出}`。

只有不同最终任务会改变学习方法时才拆分。例如“掌握 API”可能包含识别 API、读接口文档、完成接入和定位调用故障；不要为了完整而无限拆解。

## 2. 判断是否需要处理未见情况

- 未来只需复现固定原文、命令或符号对应时，重点训练准确记忆。
- 未来要处理新案例、新需求、新参数或新故障时，必须建立可泛化模型，并用表面不同、结构同类的未见情况验收。

不能用已见案例的熟练度冒充泛化能力。

## 3. 明确输入、处理和输出

任何能力优先表达为：

> 输入 → 判断或处理 → 输出

输入输出不清时，不急着选择教程、案例或练习方式。

## 4. 判断本次要建什么

| 类型 | 任务形态 | 合适材料与学习方式 |
|---|---|---|
| 固定对应 | 符号或命令 → 固定名称、含义或动作 | 准确记忆与复现，不强行设计归纳 |
| 判别模型 | 任意新对象 → X / 非 X 或某类别 | 正例、反例、边界例、判别条件、未见测试 |
| 连接或处理模型 | 已识别为 X → 会发生什么、怎样处理 | 输入变化、条件变化、输出变化、因果证据 |
| 外显知识 | 能说清、比较、推导的关系 | 意识分析、结构化表达与边界检查 |
| 内隐能力 | 实时识别、熟练操作、听辨或调试直觉 | 多样直接经验、及时反馈、渐增变化与重复 |
| 程序性综合能力 | 判断、操作、观察、反馈与故障恢复 | 交给 `pao-tong` 的真实任务和证据训练 |

同一学习目标可以包含多种类型。只拆会改变材料、训练或验收方式的子任务。

## 5. 三层学习诊断

1. **语言或符号层**：认识名称、缩写、定义句、代码符号、命令或字段名。
2. **意义层**：建立概念、判断条件、输入输出、关系、因果和适用范围。
3. **现实对象或操作层**：能在真实案例、系统、数据、日志或需求中正确识别和处理。

知道 `agent = 智能体` 只证明符号指代，不证明理解 Agent。语言材料是建构意义的材料，不是知识本身。

## 6. 学习失败与定向修复

| 可观察表现 | 诊断 | 修复策略 |
|---|---|---|
| 只知道术语名字 | 只记名称 | 补当前语境中的指代和现实对象 |
| 会背定义但不会判断 | 言存意空或下层不足 | 补真实对象、正反例、边界例和判别条件 |
| 案例做过很多，换场景不会 | 上层丢失 | 比较案例，提取不变结构、变量和边界 |
| 理论和案例都有，但套错 | 下上层错配 | 先检查对象归类、概念内涵和输入空间 |
| 原案例很快，新案例不会 | 熟练度高、泛化不足 | 使用结构同类但表面不同的未见任务 |
| 知道规则但实时做不到 | 外显知识已有、内隐能力不足 | 增加有反馈的直接经验与渐变训练 |
| 会操作但说不清输入输出 | 程序性经验已有、模型不完整 | 回走一条真实样本或状态变化链 |
| 会解释但不会操作 | 意义层已有、程序性能力未形成 | 转入 `pao-tong` 的真实任务训练 |
| 只会中文翻译英文术语 | 指代可能建立，语境意义未建立 | 回到原句、技术体系和现实对象确认含义 |

不要统一用“再解释一遍”“再做几题”处理所有失败。

## 7. 选择材料与使用方式

- 判别模型需要表面多样的正例、反例和边界例。
- 连接模型需要输入、条件和输出变化，以及可验证因果证据。
- 内隐能力需要直接输入、正确反馈和逐渐增加的新情况。
- 工程能力需要真实任务、环境、输入输出、日志、Trace、状态和安全可恢复故障。

材料与学习方式分开判断。同一份材料可以被死记、比较、归纳、预测、排错或实际操作，结果并不相同。

课程、论文、书籍或技术文档不能默认走“原文 → 摘要 → 记忆”。除非任务要求固定原文、术语、命令或考试表达，否则优先完成：语义理解 → 对象定位 → 判别模型 → 连接模型 → 未见验证。

## 8. 未见情况与迁移边界

适合泛化的任务至少用一个结构相同但表面不同的未见案例，检查用户能否识别、预测、解释或处理。

类比只能提出待验证的新模型。迁移时说清：

- 哪些角色和输入被替换；
- 哪个不变关系可能保留；
- 哪些前提可能失效；
- 新领域是否仍属于原知识的输入空间；
- 用什么证据验证。

失败后定位具体缺口：符号识别、意义、判别条件、对象层、上层抽象、输入空间、处理模型、操作熟练度或内隐能力。不要只写“还没掌握”。
