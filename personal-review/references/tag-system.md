# 复盘标签体系

默认标签体系，覆盖常见复盘场景。每次复盘自动匹配 1-3 个标签。

## 标签定义

| 标签 | 定义 | 触发关键词 |
|------|------|-----------|
| #工作 | 职场相关、项目管理、团队协作、老板沟通、任务分配 | 老板、同事、项目、任务、 deadline、会议、方案 |
| #学习 | 课程、读书、技能提升、知识获取、学习方法 | 看书、课程、学习、笔记、听课、理解、搞不懂 |
| #人际 | 人际关系、沟通、社交、家庭、朋友 | 沟通、关系、朋友、家人、吵架、误会、表达 |
| #情绪 | 心理状态、情绪波动、焦虑、压力、自我认知 | 焦虑、烦躁、开心、压抑、情绪、心态、内耗 |
| #决策 | 重要选择、判断反思、取舍、优先级 | 决定、选择、取舍、纠结、判断、该不该 |
| #健康 | 身体、作息、运动、饮食、睡眠 | 睡眠、运动、身体、作息、疲劳、精力、健康 |
| #习惯 | 日常习惯、时间管理、自律、拖延 | 习惯、拖延、时间管理、自律、每天、坚持 |
| #认知 | 思维方式、观念转变、世界观、心智模型 | 意识到、发现、原来、突然明白、思维方式 |
| #创作 | 写作、内容生产、表达输出、创意 | 写、文章、输出、表达、创作、公众号、文案 |
| #杂想 | 无法归类的随想、碎片化思考 | 其他内容不匹配以上标签时使用 |

## 标签匹配规则

1. 优先匹配最具体的标签（如提到"跟老板沟通" → #工作，而不是 #人际）
2. 一条复盘最多 3 个标签，最少 1 个
3. 如果内容同时涉及多个维度，按相关度排序
4. 无法确定时默认使用 #杂想

## 扩展规则

如果用户在使用过程中形成了新的标签偏好：
- 记录在本文件末尾
- 更新索引文件中的标签统计
