# 双向钢人决策

把用户的当前想法和最强反方放到同一套事实、目标与约束下比较。逻辑完整不等于事实成立；先守住证据边界，再增强论证。

## 执行流程

### 1. 定义真实决策

用一小段话重述用户真正要决定的事，至少写清以下内容：

- 要做出的选择
- 想实现的目标
- 已知约束与期限
- 用户当前倾向
- 选择错误的主要代价

不要擅自把用户没说过的动机、价值观或经历补成事实。问题仍然模糊时，先给出最合理的暂定理解，并标注“暂定”。

### 2. 分开事实、假设与偏好

把会影响结论的信息分成三类：

- 已确认事实
- 尚未核实的假设
- 个人偏好或价值选择

若结论依赖价格、政策、产品能力、法律要求、技术指标或其他可能变化的外部事实，先检索可靠来源或请用户提供材料。无法核实的内容保留为待确认项，不得为了让论证更有力而编造证据。

### 3. 构建双向最强论证

分别给出两个版本：

1. 支持用户当前倾向的最强论证
2. 反对当前倾向或支持最佳替代方案的最强论证

两边使用相同评价维度，例如收益、成本、时间、可逆性、风险、能力积累和长期影响。每条论证说明依赖的事实或假设。不要攻击弱化后的对方观点，也不要为了形式对称而制造虚假平衡；一方证据明显更弱时直接说明。

### 4. 找出决定结论的变量

从双方论证中提炼：

- 真正分歧是什么
- 哪一至两个变量最可能改变结论
- 什么新证据会推翻当前判断
- 哪些差异只是表述不同，不影响选择

优先寻找能观察、能测量或能用小实验验证的变量。

### 5. 只问一个关键问题

只有在答案确实可能改变结论时，提出一个问题。该问题应同时满足：

- 用户能够回答
- 答案会让选择发生变化
- 不把多个问题塞进一句话
- 不索要一整套补充材料

提出问题后停止，等待用户回答。若用户已提供答案、明确要求立即判断，或缺失信息不会改变结论，则跳过追问。

### 6. 给出明确判断与行动

用户回答后，按以下顺序输出：

1. **判断**　明确选择哪一项，或明确暂缓决定
2. **核心理由**　列出最能左右结论的两至三点
3. **成立条件**　说明判断依赖哪些事实和假设
4. **反转条件**　指出出现什么证据时应改变决定
5. **下一步行动**　给出最小、具体、可执行的动作
6. **复盘节点**　在适合时说明何时重新评估

不要用“视情况而定”回避选择。证据不足时，可以明确判断“先验证再决定”，同时给出验证方法、完成标准和期限建议。

## 输出格式

首次分析默认保持紧凑：

```text
你真正要决定的事
...

支持当前想法的最强论证
...

反对当前想法的最强论证
...

真正的分歧与关键变量
...

我只问一个问题
...
```

用户回答后再输出最终判断。若用户要求一次性完成，则把“一个问题”改成“缺失信息与暂定假设”，直接给出有条件的判断。

## 质量门禁

- 不展示或索要模型隐藏的逐步思维过程，只给可核验的理由、证据与判断依据。
- 不把表达更完整误当成事实更可靠。
- 不因用户已有倾向就默认支持，也不为显得客观而机械反对。
- 不把钢人论证用于证明阴谋、歧视、违法伤害或明显虚假的前提。
- 医疗、法律、财务和安全等高风险决策，先核验当前权威信息，并明确专业复核边界。
- 情绪性困扰中先确认用户需要决策分析还是倾听支持；不要把所有个人感受都改造成辩论题。
