# 小红书图文爆文分析方法论

## 核心理念

分析别人的爆款小红书笔记，提取**钩子 + 骨架 + 行动刺点**三件套，帮学员把爆款逻辑套到自己的赛道。

小红书是**搜索+推荐双流量**的图文平台。观众行为是跳读、回读、收藏、评论——跟视频的线性观看不同。所以分析笔记要围绕：

- **为什么点进来** → 钩子（主要在标题，其次在正文前3行）
- **为什么读完** → 骨架（正文分段节奏）
- **为什么互动** → 行动刺点（点赞/收藏/评论/传播/关注）

---

## 每条笔记 = 需求 + 解决方案

分析笔记时要先识别：

- **目标人群**：这条笔记在钓什么人？（具体人群标签 + 场景）
- **观众需求**：看这条是为了什么？（想学东西 / 想被安慰 / 想看热闹 / 想找共鸣 / 想抄作业）
- **解决方案**：这条用什么方式满足了需求？

这一步是后面钩子、骨架、刺点分析的**锚点**。

---

## 骨架三步法

拆骨架的核心方法，从 chaipian 继承而来，图文版完全适用。

### 步骤A：分段落

按**事件发展**或**转折词**分自然段。分段依据：

- 话题/事件发生转换
- 出现明显的转折词、连接词
- 说话对象发生变化
- 时间线发生跳跃
- 表达目的发生变化

### 步骤B：标注每段逻辑

用**大白话**总结每段：

- 这段写了什么？
- 为什么写这段？
- 它在整篇笔记里起什么作用？

**关键原则：用人话总结，不用抽象术语。** 不说"虚荣镜像"，说"描述一个做得好的人"。

### 步骤C：剔除具体元素，只留骨架

| 要剔除的 | 替换为 |
|----------|--------|
| 具体人名 | "一个人""某个人" |
| 具体事件 | "做一件事""完成一个心愿" |
| 具体行业词 | "某个领域""这方面" |
| 具体数据 | "原来的状况""取得的成绩" |
| 具体场景 | "某个地方""某个环境" |

### 骨架输出的两段式

分析完所有段落后，输出两部分：

**1. 复用框架**

```
【框架名称】____型：____式
【适用场景】____

【结构流程】
① ____
② ____
③ ____
...
```

**2. 逐步仿写公式**

```
第①步 — ____
- 作用：____
- 仿写公式：____（句式模板）
- 示例：____

第②步 — ____
...
```

## 语言质量判断

分析笔记时注意原笔记的语言质量：

- **直观语言 > 抽象语言**
- **do句式 > be句式**（"我每天四点起来熬汤" > "我是一个勤奋的人"）
- **有专属细节 > 泛泛而谈**（"揣着一张车票" > "我来到了大城市"）
- **有节奏感 > 平铺直叙**
- **有故事感 > 抽象说理**
- **"故事感 = 特定感"**

## 三赛道改写范文的生成原则

Phase 6 的核心产出，**直接决定 skill 对学员的实用性**。

### 选赛道的原则

从以下通用赛道池随机选 **3 个差异较大**的赛道：

```
职场 / 理财 / 情感 / 育儿 / 健身 / 美妆 / 护肤 / 穿搭
学习 / 考公 / 副业 / 美食 / 家居 / 旅行 / 宠物 / 数码
```

**差异较大**的意思是 3 个赛道的目标人群、痛点、话语体系都不一样，这样学员能看到"同一个骨架在完全不同领域怎么变形"。

### 改写范文的完成度要求

**必须达到学员可以直接抄走微调即发的程度**：

- 标题要**完整成型**，不能是"____的3个方法"这种模板
- 正文要**完整段落**，不能是"（此处写钩子）（此处讲故事）"这种占位符
- 钩子类型要**明确对应**原笔记用的钩子
- 刺点要**真的埋进去**，不是在末尾列个清单
- 长度跟原笔记匹配（原笔记多长，改写就多长）

### 骨架抽象原则：保留动作，不保留句式 ⚠️

这是改写时最容易踩的坑。骨架抽象要**抽到动作层**，不能连原文的具体句式一起搬。

**✅ 保留（动作流程）：**
- 结构动作：抛主张 / 排比反差 / 观点+例子 / 金句收尾
- 信息流逻辑：先说什么、再说什么、每段干什么
- 钩子类型 + 刺点分布

**❌ 不保留（原文的具体表达）：**
- 原文的具体开头句式（例如"你应该XX，然后XX"）
- 原文的具体金句公式（例如"拥有XX的能力，就不怕XX"）
- 原文的具体过渡语（例如"另一个例子""我惊奇地发现""趁着XX分享心法"）
- 原文的具体标点/emoji 用法
- 原文的段落命名方式（例如"心法1/心法2"）

**反面示范（错误）：**
三个赛道改写全部用"你应该XX，然后XX"开场 + "拥有XX的能力，就不怕XX"并列金句 + "1️⃣2️⃣3️⃣心法"结构——这不是套骨架，是换关键词的复制粘贴。

**正面做法：**
每个赛道要有**自己独立的话语体系**——
- 健身赛道：短句爽文、直给、自带冲击感
- 育儿赛道：絮叨、共情、姐妹聊天感
- 考研赛道：冷静、数据化、学长干货感
- 美妆赛道：种草感、细节多、姐妹分享
- 职场赛道：理性、结构化、专业感

骨架动作一样，但开头句式、金句风格、过渡语、段落命名、收尾方式——全部要按新赛道重写。

### 改写时要保留的

- 原笔记的**钩子类型**（保持同一种或叠加一种）
- 原笔记的**骨架动作流程**（第①②③步的动作逻辑，不是具体句式）
- 原笔记的**刺点分布**（哪段埋点赞、哪段埋收藏等）

### 改写时要替换的

- 目标人群（换成新赛道的人群）
- 场景细节（换成新赛道的典型场景）
- 具体数字/经历/金句内容
- **话语体系**（最关键）：开头句式、金句格式、过渡语、段落命名、整体语气——全部要贴合新赛道的惯用表达

---

## 输出语言与风格

- 全程使用**中文**输出
- 骨架和仿写公式使用**大白话**，不用"Hook""CTA"等术语
- 每个拆解点要**具体到每一步该怎么做**
- 改写范文要**具体到可以直接发布**的完成度
- **直观语言 > 抽象语言**，**有专属细节 > 泛泛而谈**
- 目标用户是新手学员，术语要浅、示范要清楚

---

## 不适合拆的笔记类型

| 类型 | 原因 |
|------|------|
| 纯视觉向（穿搭九宫格、风景大片） | 吸引力在图不在字，文案几乎为空 |
| 明星/公众人物号 | 靠身份获取流量，不可复制 |
| 投流型笔记 | 数据不真实，骨架不一定有参考价值 |
| 纯种草带货硬广 | 商业逻辑不是内容逻辑 |
| 评论区爆而正文平的 | 爆款原因在评论不在笔记本身 |

遇到这些类型，提前告知学员并建议换一篇。
