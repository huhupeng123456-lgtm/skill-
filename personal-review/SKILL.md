# 个人复盘助手

## 触发条件

用户有以下任何请求时触发：
- 帮我复盘
- 整理一下这段录音
- 提炼复盘
- 这段文字帮我整理成复盘
- 写进OBS
- 把这段随想整理一下

## 核心原则

**提炼精准第一**：宁可多保留一点，也不能把真正有价值的反思删掉。去水不等于去细节，口语废话要删，但情绪、洞察、具体场景必须保留。

**口语化输入 → 结构化输出**：输入可以是你想到哪说到哪的口水话，输出必须是能放进知识库、半年后还能看懂的正经笔记。

**关联才有价值**：单条复盘只是记录，关联历史才能发现模式。每次复盘都要扫描历史，找出重复出现的问题或主题。

## 工作流程

### 步骤 1：读取输入

读取用户提供的文件或文本：
- .txt / .md：直接读取
- .doc / .docx：提取纯文本
- .pdf：提取文字层
- 纯文本粘贴：直接分析

### 步骤 2：口语去水

删除以下口语填充词和无效表达（保留核心语义）：
- 填充词：嗯、啊、那个、这个、就是、然后、对吧、你知道吧、我觉得吧、怎么说呢
- 重复表述：同一句话换着花样说三遍，保留最清楚的那一遍
- 自谦/客套："我可能说得不对""随便聊聊"等开场白，直接删除
- 口头禅：个人高频但无意义的词（如"老实说""其实吧"）

**注意**：删除后必须通读一遍，确认没有删掉包含情绪、判断、具体事件的关键句。

### 步骤 3：复盘提炼

从去水后的内容中，按以下标准提取值得记录的部分：

| 类型 | 判断标准 | 示例 |
|------|---------|------|
| **教训** | 做错了什么、为什么错、下次怎么做 | "上次跟老板对齐需求时没有确认DOD，导致返工三天" |
| **洞察** | 突然想通的道理、反常识的发现 | "原来设定上限不是偷懒，而是保护长期战斗力" |
| **情绪** | 真实的情绪波动及触发原因 | "那天特别焦虑，因为满脑子都是没头绪的大任务" |
| **决策** | 做了什么选择、基于什么判断 | "决定不再接没有明确完成定义的任务" |
| **试错** | 试了什么东西、结果如何 | "试了两周设定上限，第二周脑子清醒多了" |
| **模式** | 重复出现的行为或思维习惯 | "每次都是状态好就多干一点，然后第二天崩溃" |

提取规则：
- 不要概括，保留具体细节（时间、人物、事件、结果）
- 保留第一人称"我"，保持个人感
- 保留当时的情绪和判断，不要事后理性化
- 如果没有上述六类内容，如实告诉用户"这段内容没有提炼出值得复盘的价值点"

### 步骤 4：自动标签

根据提炼内容，从标签体系中自动匹配 1-3 个标签。匹配规则：
- 看内容中涉及的场景和主题
- 不强制每个复盘都必须有标签，如果内容无法归类，可以只打 #杂想
- 多个标签按相关度排序

详见 `references/tag-system.md`

### 步骤 5：历史关联

扫描 Obsidian 知识库中的历史复盘文件，找出关联：

1. 读取 `references/obsidian-guide.md` 中配置的复盘目录
2. 提取历史复盘的标题、日期、标签、核心内容
3. 与本次复盘做主题匹配（基于关键词和标签）
4. 输出关联提示（如果有）：
   - "你X个月前也提过类似的问题..."
   - "这是第N次提到这个主题..."
   - "建议回头看看某年某月某日的复盘"

如果历史复盘数量太多（超过20篇），优先读取最近半年的，再按标签筛选相关主题。

### 步骤 6：生成输出

整合为以下结构：

```
# YYYYMMDD [提炼后的主题]

标签：[标签1] [标签2]

## 原文摘要
[用2-3句话概括这次复盘的核心内容]

## 提炼内容

### [类型1：如教训]
[具体细节]

### [类型2：如洞察]
[具体细节]

...

## 历史关联
[如果有的话，列出关联的历史复盘及日期]

## 写在最后
[可选：一句总结或给自己的话]
```

### 步骤 7：写入OBS

1. 按命名规范生成文件名：`YYYYMMDD_[主题关键词].md`
2. 写入 `references/obsidian-guide.md` 中配置的复盘目录
3. 如果目录不存在，告知用户路径，让用户确认后再写入
4. 写入完成后告知用户文件路径

## 输出格式要求

- 不使用 Markdown 加粗符号（**），保持笔记简洁
- 用口语化短句，换行分段
- 每个段落只讲一件事
- emoji 适度使用，不要每段都加

## 质量自检

完成输出前检查：
- [ ] 口语填充词是否已清理？
- [ ] 是否有具体细节（时间/人物/事件/结果）？
- [ ] 是否有六类内容（教训/洞察/情绪/决策/试错/模式）中的至少一类？
- [ ] 标签是否匹配内容主题？
- [ ] 是否扫描了历史复盘并给出关联提示？
